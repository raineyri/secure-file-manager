# Secure File Manager

Учебное консольное приложение для безопасного управления файлами с использованием реляционной базы данных SQLite.

Приложение реализовано на Python и поддерживает основные файловые операции, работу с форматами JSON и XML, создание и безопасное извлечение ZIP-архивов, аутентификацию пользователей и журналирование действий.

## Основные возможности

Приложение поддерживает:

- регистрацию и аутентификацию пользователей;
- хранение паролей в виде хешей Argon2id;
- получение сведений о доступных смонтированных файловых системах;
- создание текстовых файлов;
- чтение файлов;
- изменение файлов;
- удаление файлов;
- просмотр списка файлов пользователя;
- чтение и запись JSON;
- чтение и запись XML;
- создание ZIP-архивов;
- безопасное извлечение ZIP-архивов;
- журналирование операций пользователей в SQLite;
- разграничение доступа пользователей к файлам;
- автоматизированное тестирование с использованием pytest.

## Механизмы безопасности

При разработке приложения были реализованы следующие защитные механизмы.

### Защита от SQL Injection

Все SQL-запросы, содержащие пользовательские данные, выполняются с использованием параметризованных выражений.

Пример:

```python
connection.execute(
    """
    SELECT id, username, password_hash
    FROM users
    WHERE username = ?
    """,
    (username,),
)
```

Это предотвращает интерпретацию пользовательского ввода как части SQL-запроса.

### Безопасное хранение паролей

Пароли пользователей не сохраняются в открытом виде.

Для их хеширования используется алгоритм Argon2id через библиотеку `argon2-cffi`.

### Защита от Path Traversal

Все пользовательские пути ограничиваются рабочей директорией `storage`.

Приложение блокирует абсолютные пути и попытки выхода за пределы рабочей директории с использованием последовательностей вида:

```text
../../
```

Например, попытка обращения к:

```text
../../etc/passwd
```

будет отклонена.

### Защита XML

Для безопасного разбора XML используется библиотека `defusedxml`.

Она позволяет блокировать потенциально опасные XML-конструкции, включая внешние сущности, которые могут использоваться в атаках XXE.

### Защита ZIP-архивов

Перед извлечением содержимого ZIP-архива выполняются проверки:

- отсутствие абсолютных путей;
- отсутствие компонентов `..`;
- запрет символических ссылок;
- ограничение количества файлов;
- ограничение размера отдельного файла;
- ограничение суммарного объёма извлекаемых данных;
- контроль коэффициента сжатия;
- проверка принадлежности архива текущему пользователю.

Это позволяет снизить риск атак ZipSlip и архивов с аномально высоким коэффициентом сжатия.

## Назначение модулей

`auth.py` отвечает за регистрацию пользователей, аутентификацию и хеширование паролей.

`database.py` создаёт подключение к SQLite и формирует таблицы пользователей, файлов и операций.

`file_service.py` реализует файловые операции, контроль путей, разграничение доступа и получение информации о файловых системах.

`json_service.py` реализует сериализацию и десериализацию JSON.

`xml_service.py` реализует создание XML и его безопасный разбор.

`archive_service.py` реализует создание и безопасное извлечение ZIP-архивов.

`audit_service.py` отвечает за запись и получение событий аудита.

`main.py` реализует консольный пользовательский интерфейс.

## Установка

Требуется Python 3.10 или совместимая версия.

Создание виртуального окружения:

```bash
python3 -m venv .venv
```

Активация:

```bash
source .venv/bin/activate
```

Установка зависимостей:

```bash
python -m pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска пользователь может зарегистрироваться либо выполнить вход в существующую учётную запись.

## Автоматизированное тестирование

Для запуска тестов используется pytest:

```bash
pytest -v
```

Набор тестов проверяет:

- регистрацию пользователя;
- корректную и ошибочную аутентификацию;
- отсутствие хранения пароля в открытом виде;
- устойчивость аутентификации к тестовой SQL-инъекции;
- создание, чтение, изменение и удаление файлов;
- разграничение доступа между пользователями;
- блокирование Path Traversal;
- работу JSON;
- работу XML;
- блокирование XXE;
- создание и извлечение ZIP;
- блокирование ZipSlip;
- блокирование архивов с аномальным коэффициентом сжатия;
- запрет извлечения архива другого пользователя.

На текущем этапе набор содержит 20 автоматизированных тестов.

## Хранение данных

Рабочие файлы приложения размещаются в каталоге:

```text
storage/
```

SQLite-база данных создаётся автоматически в каталоге:

```text
data/
```

Каталоги с рабочими данными и база данных не должны добавляться в Git-репозиторий.

## Используемые библиотеки

Основные внешние зависимости:

- `argon2-cffi` — хеширование паролей;
- `defusedxml` — безопасная обработка XML;
- `psutil` — получение информации о файловых системах;
- `pytest` — автоматизированное тестирование.

## Назначение проекта

Проект разработан в учебных целях для демонстрации подходов безопасной разработки программного обеспечения, включая минимизацию доверия к пользовательскому вводу, безопасную обработку файлов и архивов, разграничение доступа, защиту данных пользователей и автоматизированное тестирование.
